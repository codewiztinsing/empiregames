How Bonus Settings Work

  • Bonus Countdown: Controls the countdown timer displayed on the main game screen
  • Game Speed: Determines how fast numbers are called during games
  • Real-time Updates: Changes are reflected immediately on the main screen
  • Admin Control: Only administrators can modify these settings
  • API Integration: Settings are fetched by the main screen every 30 seconds
